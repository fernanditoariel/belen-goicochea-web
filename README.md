# Belén Goicochea — sitio profesional

Sitio web profesional de Belén Goicochea, profesora de Educación Física, personal trainer, instructora de Pilates Reformer y profesora de natación en Bahía Blanca.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

## Verificaciones

```bash
pnpm lint
pnpm build
```

El proyecto está preparado para importarse directamente en Vercel. No requiere variables de entorno, base de datos ni servicios externos.
